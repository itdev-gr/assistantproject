# 2026 price list

Decisions behind migration `0018_pricing_2026.sql`, `apps/web/src/lib/plans.ts` and `hotel-plans.ts`.

## Packages (yearly, VAT included)

| Audience | Package | Price | DB key |
|---|---|---|---|
| Hotels | Basic / Professional / Advanced / Enterprise | 990 / 1.490 / 1.990 / 2.990 € | `hotels.plan` |
| Small accommodation (Airbnb, apartments, studios, villas) | Accommodation | 149 € | `hotels.plan = 'accommodation'` |
| Businesses | Business / Premium Partner | 149 / 299 € | `businesses.subscription_tier = 'standard' \| 'featured'` |

`exclusive` stays in the `subscription_tier` enum for legacy rows but is not sold, not shown, and not accepted at signup.

## Launch offer

The first 50 hotels pay 990 € for their first year regardless of package. A slot is claimed atomically (`claim_launch_offer`) when the owner starts Checkout for Professional / Advanced / Enterprise (Basic and Accommodation are not discounted and do not consume slots). The discount is a Stripe coupon (`launch50_<plan>`, `duration: 'once'`), so year two renews at list price. Slots claimed but never paid are released by the nightly reconciler after 3 days (`launch_offer_stale`).

Resolution: per-hotel `feature_flags` row → package default (`hotelPlanFeatures`). Global flag rows are ignored. Gating is not tied to `billing_status` (existing decision). Only `llmChat` (chat route) and `partnerConnections` (owner partners page) are enforced in code today.

## Commission

"Standard commission — up to 10%, depending on the partnership." Enforced for new inputs (admin editor, connection requests, `create_partnership_request`). Existing partnerships above 10% are kept and flagged in the admin list; they can only be lowered.

## Rollout

1. `supabase db push --linked`, `pnpm db:types`.
2. `node scripts/setup-stripe-products.ts` in live mode → set `STRIPE_PRICE_STANDARD/FEATURED` (new yearly ids), the five `STRIPE_PRICE_HOTEL_*`, `NEXT_PUBLIC_CONTACT_EMAIL`; remove `STRIPE_PRICE_EXCLUSIVE`, `STRIPE_PRICE_HOTEL`.
3. Stripe customer portal: allow switching only among the 7 yearly prices.
4. Deploy, run the reconciler once; the one hotel on the old monthly €49 price shows as `legacy_price` until moved via the portal or cancel + re-checkout. Archive the old monthly prices afterwards.
